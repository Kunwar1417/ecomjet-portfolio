Proposals

Local only, not deployed

Per-brand pitch decks live in the repo as proposal-{brand}-print.html and are usually exported to PDF and emailed rather than deployed. They all carry noindex. As of today none of them are live, they return 404. If you ever deploy one, it becomes a real URL and belongs in this list.

Why this matters most here. Each proposal names a brand and quotes a price. If one brand finds another brand's proposal, your whole pricing ladder is visible and every future negotiation starts from your lowest number. Keep them out of the deployed site unless you have a reason.

Adding a new private page

Four steps, all required
  1. Put <meta name="robots" content="noindex, nofollow" /> in the head, directly under the viewport tag. This is the one that actually works, since it tells search engines not to list the page even if they reach it some other way.
  2. Add a Disallow: line to robots.txt for both the clean path and the .html one.
  3. Keep it out of sitemap.xml, which should only ever list public pages.
  4. Add a row to this page, so the list stays complete.

Checking nothing leaked

Worth doing every few months
  1. Search Google for site:theecomjet.com and read the results. Only public pages should appear.
  2. If a private page shows up, robots.txt will not remove it. Blocking the crawl stops Google from ever seeing the noindex tag. Use the removal tool in Search Console instead.
  3. From the repo, grep -L 'name="robots"' *.html lists every page missing a noindex tag. Cross-check anything unexpected against this list.
